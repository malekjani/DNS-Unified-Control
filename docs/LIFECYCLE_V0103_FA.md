# DNS Unified Control v0.10.3 — Lifecycle Manager

## نصب، ادامه، ترمیم و ارتقا با یک دستور

پس از استخراج بسته و ورود به پوشه پروژه، **فقط** دستور زیر را اجرا کنید:

```bash
sudo bash install.sh
```

نصب‌کننده ابتدا Manifest را بررسی کرده و سپس با خواندن `VERSION` کد نصب‌شده، `/etc/dns-unified/instance.json` و ژورنال Lifecycle تصمیم می‌گیرد:

| حالت | شرط | رفتار |
|---|---|---|
| Fresh | نصب و هویت قبلی وجود ندارد | ارزیابی فقط‌خواندنی، درخواست دامنه/IP و انتخاب‌های اختیاری، تأیید، نصب پایه |
| Resume | ژورنال ناتمام از همان انتشار یا هویت نصب نیمه‌تمام | بازبینی هویت، اجرای دوباره مراحل ناقص و مراحل با اعتبارسنجی ناموفق |
| Upgrade | نسخه نصب‌شده قدیمی‌تر از بسته است | بررسی، Snapshot، ارتقای Web/Agent، تست واقعی سلامت؛ حفظ کلیدها و خدمات تونل |
| Repair | همین نسخه نصب شده است | ترمیم مجوزهای اجرا و بازآزمایی Web/Agent/Dante، بدون بازسازی کلیدها |
| Legacy upgrade | برنامهٔ قبلی نصب شده ولی instance.json ندارد | نیاز به تأیید صریح و Backup؛ هویت سرور قدیمی خودسرانه عوض نمی‌شود |
| Downgrade | نسخه نصب‌شده جدیدتر از بسته | رد عملیات، بدون تغییر |

در هر حالت تغییردهنده، برنامه تأیید متنی متناسب با عملیات می‌خواهد، مانند `APPLY-UPGRADE-0.10.3`؛ اجرای بدون TTY برای این اقدامات رد می‌شود.

## دستورهای ایمن عیب‌یابی

```bash
cd /root/dns-unified-control
sudo bash install.sh --dry-run      # فقط تشخیص عملیات، بدون تغییر
sudo bash install.sh --status       # وضعیت مراحل و خطاها، بدون تغییر
sudo bash install.sh --repair       # ترمیم در صورت برابر بودن نسخه نصب شده
```

ژورنال در `/var/lib/dns-unified/lifecycle/state.json` با مجوز 0600 و پوشه 0700 قرار دارد؛ فیلدهای آن شامل شناسه Instance، نسخه، مراحل انجام‌شده، نوع خطا و وضعیت گواهی است. **هیچ Token، رمز پنل، کلید خصوصی یا رمز Dante داخل ژورنال نوشته نمی‌شود.** قفل هم‌زمانی در `/run/lock/duc-lifecycle.lock` قرار دارد.

تست پایان مراحل شامل پاسخ HTTP از `127.0.0.1:8088`، درخواست **واقعی** `GET /status` از Unix Socket Agent و وضعیت معتبر Dante روی `127.0.0.1:1080` است. فقط فعال‌بودن systemd به معنی Ready نیست.

## وضعیت HTTPS و DNS

آماده بودن محلی با آماده بودن عمومی یکی نیست:

- `LOCAL_READY_PUBLIC_PENDING`: Web/Agent/Dante محلی بررسی شده‌اند؛ انتقال DNS یا گواهی عمومی هنوز ممکن است تکمیل نباشد.
- `READY`: علاوه بر سلامت محلی، گواهی HTTPS معتبر محلی و A پنل روی IP همین سرور تأیید شده‌اند.

این وضعیت **به معنی موفقیت تونل اینترنت یا تست همه ۹ موتور نیست**. عملیات Cloudflare، تغییر رکورد A، فعال‌کردن UDP/53، صدور DNS-01 و ساخت کلاینت همچنان مرحله‌های مستقل و نیازمند تأیید هستند. هیچ‌کدام هنگام اجرای `install.sh` به‌صورت خودکار انجام نمی‌شوند.

## Snapshot و Rollback

در Upgrade، کد برنامه و Unitهای systemd در `/var/backups/dns-unified` با مجوز root-only (0700 برای پوشه و 0600 برای فایل) Snapshot می‌شوند. هنگام خرابی Apply یا Health، Lifecycle تلاش می‌کند **همین کد و Unitها** را به حالت قبل برگرداند و سرویس Web/Agent را دوباره بارگذاری کند. از انجام این کار برای فایل‌های `/etc/dns-unified/keys`، TOTP، Dante، Cloudflare، سرویس موتور فعال یا باینری‌های موتورها خودداری می‌شود.

**محدودیت:** این Rollback یک تراکنش کامل سیستم‌عامل نیست؛ نسخه بسته‌های APT/Pip، مهاجرت‌های داده‌ای، فایل‌های جانبی بیرون از `/opt/dns-unified-control` و تغییرات upstream را خودکار به حالت قبل برنمی‌گرداند. پیش از ارتقای سرور تولید، Snapshot سطح VPS و بکاپ رمزگذاری‌شدهٔ کلیدها و داده‌ها داشته باشید. `SHA-256 release-manifest.json` فقط صحت فایل‌ها را می‌سنجد، نه امضای ناشر.

در صورت خطا، از اجرای مجدد `fresh-install.sh --install` خودداری کنید؛ از همان `sudo bash install.sh` و `--status` استفاده کنید.

## وضعیت VPS فرانسه

در سرور `13.39.238.230` با `m2m.diy` که نسخهٔ 0.10.1/0.10.2 و هویت مستقل دارد، انتظار می‌رود نصب‌کننده حالت **Upgrade** را انتخاب کند و دوباره IP، دامنه یا رمز ادمین را نخواهد. اگر نتیجهٔ `--dry-run` خلاف این بود، اجرای تغییردهنده را آغاز نکنید. سرور قدیمی و Cloudflare تا آزمون کامل کلاینت‌ها نباید دست‌کاری شوند.

## محدودیت‌های انتشار

نسخهٔ 0.10.3 روی سورس و تست‌های خودکار آزمایش می‌شود و آزمون زندهٔ نصب در EC2 هنوز نیازمند اجرای واقعی روی VPS است. این انتشار محصول را در زمینه Lifecycle منظم‌تر می‌کند، اما هنوز بستهٔ DEB امضاشده، نصب اتمیک واقعی، بکاپ رمزگذاری‌شدهٔ خودکار و سنجش میدانی همه موتورها ندارد.
