# DNS Unified Control 0.7 — نصب قابل‌ادامه و یکپارچهٔ ۹ موتور

این نسخه مشکل اجرای دستی مراحل برای هر موتور را با یک Provisioner واحد برطرف می‌کند. تفاوت **وجود باینری**، **آمادگی پیکربندی**، **روشن بودن سرویس** و **اثبات اتصال کلاینت** در خروجی حفظ می‌شود. هیچ نصب‌کننده‌ای مجوز ادعای اتصال واقعی را ندارد.

## ارتقا روی VPS که نسخه 0.6.1 روی آن اجراست

```bash
cd /root
unzip -tq DNS-Unified-Control-v0.7.0.zip
unzip -oq DNS-Unified-Control-v0.7.0.zip
cd /root/dns-unified-control
bash upgrade.sh --install-missing
```

این دستور پیش از نصب از کد فعلی پشتیبان می‌گیرد، وب و Agent را به‌روز می‌کند، سپس فقط موتورهای ناقص را نصب یا برایشان تنظیمات لازم را می‌سازد. روی VPS یک‌گیگابایتی نصب Go به‌صورت تک‌هسته‌ای انجام می‌شود. برای Master نسخه موردنیاز Go به‌صورت `GOTOOLCHAIN=auto` دریافت می‌شود و ممکن است زمان‌بر باشد. **سرویس DNSTT فعال نه متوقف می‌شود و نه دوباره کامپایل یا جایگزین می‌شود.** به‌هیچ عنوان اسکریپت را با غیرفعال کردن یا حذف سرویس DNS اجرا نکنید.

نصب گروهی **بدون راه‌اندازی خودکار هیچ موتور دیگری** پایان می‌یابد. اگر فرایند SSH قطع شد یا نصب یک موتور خطا داد، همین دستور را مجدداً اجرا کنید؛ باینری‌های موفق حفظ می‌شوند و مراحل ناقص دوباره بررسی می‌شوند.

## حالت پیش‌نمایش، گزارش و اجرای انتخابی

```bash
sudo env PYTHONPATH=/opt/dns-unified-control /opt/dns-unified-control/.venv/bin/python -m duc.provision --dry-run
sudo env PYTHONPATH=/opt/dns-unified-control /opt/dns-unified-control/.venv/bin/python -m duc.provision --report
sudo env PYTHONPATH=/opt/dns-unified-control /opt/dns-unified-control/.venv/bin/python -m duc.provision --only master
```

فایل نتیجه در `/var/lib/dns-unified/provision-report.json` نگهداری می‌شود و داخل بخش «راه‌اندازی و کلاینت‌ها» قابل مشاهده است. فایل شامل رمز خصوصی نیست.

وضعیت‌های کلیدی:

- `preserved-running`: موتور روشن حفظ شده؛ نصب دوباره انجام نشده است.
- `present-ready`: باینری و تنظیمات حاضرند؛ بدون تغییر رد شده است.
- `installed-ready`: نصب و پیش‌نیازهای محلی موفق؛ هنوز اتصال واقعی نیازمند تست است.
- `installed-needs-config`: باینری نصب شده، ولی آماده روشن‌شدن نیست (عمدی در بعضی موتورها).
- `deferred-heavy`: موتور Rust به دلیل مصرف RAM/دیسک به‌طور پیش‌فرض کامپایل نشده است.
- `requires-review`: موردی مانند NoizDNS fork یا XDNS نیازمند نگاشت و تأیید نسخه بالادستی است؛ نصب خودکار ایمن ارائه نشده است.
- `failed`: تلاش نصب با خطا مواجه شده؛ توضیح و وضعیت آمادگی ذخیره شده است.

## درباره ۹ موتور

| موتور | برنامهٔ نصب گروهی | کانفیگ/کلاینت |
|---|---|---|
| DNSTT | حفظ موتور در حال اجرا | کلید موجود حفظ می‌شود؛ ZIP کلاینت قابل ساخت |
| MasterDnsVPN | ساخت از سورس با Go جدیدتر | `base.toml` از نمونه رسمی و رمز مشترک فقط یک‌بار ساخته می‌شود؛ کلاینت SOCKS5 از همان سورس ساخته می‌شود |
| VayDNS | ساخت Go | کلید عمومی/خصوصی، بستهٔ کلاینت Linux amd64 از همان سورس |
| Soar | تلاش برای ساخت Go | برای جلوگیری از پراکسی عمومی ناامن، تأیید امنیتی دستی لازم است |
| iodine | پکیج رسمی Ubuntu | رمز به‌صورت محلی ساخته می‌شود؛ رمزگذاری ذاتی ندارد |
| dns2tcp | پکیج رسمی Ubuntu | کلید مشترک محلی؛ رمزگذاری ذاتی ندارد |
| SlipStream Rust | پیش‌فرض: defer | با `--include-heavy` فقط در صورت منابع و ابزار لازم، تلاش build؛ ساخت TLS cert/seed |
| NoizDNS | نیازمند review | تنوع CLI و PT-mode، بدون فرض سازگاری DNSTT |
| XDNS | نیازمند review | فایل Xray/FinalMask رسمی و تنظیمات native معتبر لازم است |

## نکات طراحی

- هیچ‌یک از عملیات نصب، پورت UDP/53 را تصاحب نمی‌کند. فقط یک موتور در زمان مشخص می‌تواند روشن باشد.
- Core سوئیچ را هنگام نصب گروهی متوقف می‌کند تا جایگزینی باینری با اجرای موتور جدید هم‌زمان نشود.
- کلید خصوصی DNSTT و دیگر موتورهای Noise هرگز وارد فایل کلاینت نمی‌شود. **استثنا: MasterDnsVPN به یک کلید اشتراکی بین کلاینت و سرور نیاز دارد؛ ZIP کلاینت آن محرمانه است و نباید برای دیگران فرستاده شود.**
- فایل‌های Master قبلی بازنویسی نمی‌شوند. اگر قالب upstream تغییر کرد و قابل تطبیق نبود، نصب به جای تولید کانفیگ معیوب با خطا/نیازمند بررسی گزارش می‌شود.
- `systemd-resolved`، `/etc/resolv.conf`، رکوردهای Cloudflare و فایروال در نصب گروهی تغییر نمی‌کنند. سازگاری UDP/53 باید پیش از سوئیچ جداگانه بررسی شود.
- وضعیت `ready` صرفاً تأیید پیش‌نیازهای محلی است. تا زمانی که از کلاینت تست نشده، سرعت و مسیر recursive DNS ثابت نشده است.
