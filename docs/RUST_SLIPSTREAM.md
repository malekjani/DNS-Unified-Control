# SlipStream Rust — سند جدید یکپارچه‌سازی

نسخهٔ پیشین این راهنما بر اساس کامپایل مخزن آرشیوشده Mygod بود و دیگر مسیر نصب پیش‌فرض **DNS Unified Control v0.7.0** نیست.

راهنمای جدید با هش‌های SHA256، اجرای Preflight، سازگاری Exclusive Mode، دستورهای چند Resolver و خروجی کلاینت:

**[SLIPSTREAM_ALIREZABEIGY_FA.md](SLIPSTREAM_ALIREZABEIGY_FA.md)**

برای حفظ سازگاری، `scripts/install-slipstream-rust.sh` به نصب‌کننده جدید هدایت می‌شود؛ هیچ کامپایل Rust اجرا نمی‌شود. نصب تنها با واردکردن `yes` انجام می‌گیرد.
