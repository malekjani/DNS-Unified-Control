# انتشار رسمی DNS Unified Control در GitHub

- نام مخزن پیشنهادی: `DNS-Unified-Control`
- نسخه نخست: `v0.10.6`
- ابتدا مخزن Private باشد؛ تصمیم برای Public شدن به بررسی مجوز Soar و سایر کدهای ثالث، امنیت و پاکسازی نمونه‌های سرور وابسته است.
- لایسنس پروژه هنوز تعیین نشده است؛ در انتشار عمومی حتماً درباره مجوز تصمیم‌گیری شود.
- `release-manifest.json` فقط صحت SHA-256 فایل‌های بسته را بررسی می‌کند؛ امضای دیجیتال نیست.
- بسته رسمی ZIP در Releases به نسخه برچسب‌خورده پیوست شود تا کاربران VPS مستقیماً با `wget` دانلود کنند.
- هرگز از نصب عملی VPS، پوشه‌های `/etc/dns-unified`, `/var/lib/dns-unified`, `/var/backups/dns-unified` یا کلیدها commit نگیرید.
- تغییر NS و راه‌اندازی موتورهای Multi بدون Preflight و تست واقعی ممنوع باشد.
